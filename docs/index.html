CPilot

A superlight native macOS app for running AI coding sessions from your menu bar. Tabs for many sessions, one calm chat, approvals you control, and pull requests from branch to merge.

DownloadView on GitHub

Many sessions, one pane

Tabs or a side list. Idle sessions sleep and resume with full context.

Claude and any ACP agent

Claude through its command line, other agents from the official registry in one click.

Approvals you control

Allow once, for the session or per project. Touch ID for Full access. Everything is logged.

Nothing lost on a crash

Rows, drafts and session ids are saved as you go. Resume exactly where you were.

Capture

One shortcut sends a screenshot, error, page or snippet straight into the chat.

Pull requests

Diff, review, security scan and automatic merge, through your own GitHub login.

Install

curl -fsSL https://raw.githubusercontent.com/kalahroudi/cpilot/main/scripts/install.sh | bash

macOS 15 or later on Apple silicon. First launch checks what is missing and sets it up.
