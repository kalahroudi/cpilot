# CPilot

A superlight native macOS menu bar app for running and managing AI coding agent sessions.

- Menu bar popover plus a full window, pure Swift (SwiftUI + AppKit), no dependencies
- Claude through its headless CLI; other agents through the Agent Client Protocol (ACP)
- Resume sessions with their context, long-term memory, multi-turn chat
- Per-session access control with one-time approval for actions on your computer
- MCP server built in, so other tools can drive CPilot
- Self-updating from GitHub releases

**Status:** design phase. The UI mockup is being reviewed; the app is not built yet.
